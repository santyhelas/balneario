# Plantillas de mail en español

Supabase → Authentication → Emails (Templates). En cada plantilla pegar el asunto (primera línea, comentario)
y el resto como cuerpo:

| Plantilla de Supabase | Archivo |
|---|---|
| Reset password        | recuperar.html |
| Invite user           | invitar.html |
| Magic link            | ingresar.html |
| Confirm signup        | confirmar.html |
